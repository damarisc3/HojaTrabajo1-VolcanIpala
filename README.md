## Hoja de Trabajo 2 — Mejoras aplicadas

En esta entrega se tomó el HTML de la Hoja de Trabajo 1 y se mejoró tanto a nivel de estructura como de estilos:

**Mejoras en HTML:**
- Se reemplazaron las tablas usadas para maquetar (header, índice, secciones) por etiquetas semánticas: `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.
- Se eliminaron las etiquetas obsoletas `<font>`, `<center>` y los atributos `bgcolor`, dejando todo el estilo a cargo del CSS.
- Se agregó texto alternativo (`alt`) descriptivo a las imágenes de la galería.
- La tabla de itinerario ahora usa `<thead>` y `<tbody>` para una estructura de datos más correcta.

**Estilos aplicados en CSS (archivo `styles.css` separado):**
- Encabezado con imagen de portada del volcán y una capa de color superpuesta para que el título resalte.
- Paleta de colores en tonos verde y dorado, inspirada en el paisaje del volcán y su laguna.
- Galería de imágenes con efecto al pasar el mouse.
- Tabla de itinerario con filas alternadas y resaltado al pasar el mouse sobre cada fila.
- Lista de actividades con viñetas en color dorado.
- Diseño responsivo con media query para que la página se adapte correctamente a pantallas pequeñas (celulares).
