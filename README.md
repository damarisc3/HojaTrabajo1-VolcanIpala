# Hoja de Trabajo 1 - Excursión al Volcán de Ipala

## Descripción del proyecto

Esta página web fue desarrollada utilizando HTML con el propósito de promocionar una excursión al Volcán de Ipala. Incluye una descripción del lugar, un índice con enlaces internos, una galería de imágenes, una tabla con el itinerario de la excursión, una lista de actividades y un pie de página.
